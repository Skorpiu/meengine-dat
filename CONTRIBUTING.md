# Contributing to Driving Academy Tool (DAT)

Thank you for considering contributing to DAT.

This project follows collaborative development practices inspired by Inner Source.

## Ways to contribute

You can contribute by:

- reporting bugs
- suggesting improvements
- improving documentation
- submitting pull requests

## Development workflow

1. Create an issue describing the change
2. Discuss the approach if necessary
3. Create a feature branch
4. Submit a Pull Request
5. Code review and merge

## Coding guidelines

- Follow existing project structure
- Keep commits small and descriptive
- Write clear commit messages
- Add comments where logic is complex

## Pull Request guidelines

- Describe the problem being solved
- Explain the approach taken
- Ensure the build passes

## Questions

If you are unsure about anything, open an issue and discuss it before implementing changes.
